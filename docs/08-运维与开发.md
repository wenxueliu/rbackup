## 12. 定时运行与同步

推荐顺序：

1. 网盘客户端持续把目的同步到云端；
2. 定时运行 `rbackup backup`；
3. 需要感知目的的变化时，运行 `watch`。

Linux/macOS cron：

```cron
15 3 * * * cd /opt/rbackup && /usr/bin/python3 -m rbackup --config /etc/rbackup.toml backup >> /var/log/rbackup.log 2>&1
```

Windows 计划任务（在“程序”里填 Python，参数填模块）：

```text
程序:   C:\Python312\python.exe
参数:   -m rbackup --config C:\Users\you\AppData\Roaming\rbackup\config.toml backup
起始于: C:\path\to\rbackup
```

如果要持续感知目的的变化，把 `watch --exit-on-change --json` 放到一个由 systemd/计划任务拉起的循环里，或将输出接到通知程序。`watch` 本身不是系统服务。

注意：rbackup 只负责 源 → 目的；目的 → 云端由网盘客户端负责。若目的本地丢失，需要先让客户端把云端数据恢复到目的，再用 `rbackup restore`。

## 14. 开发与测试

```bash
python -m compileall -q rbackup tests
python -m unittest discover -s tests -p "test_*.py" -v
```

端到端测试需要 rclone；可用 `RBACKUP_RCLONE` 指定：

```bash
RBACKUP_RCLONE=/path/to/rclone python -m unittest discover -s tests -p "test_integration.py" -v
```

测试会在 `.test-tmp/` 下创建本地源目录 + 本地 crypt 目的，不需要网盘账号，也不会访问外网。

## 15. 打包与发布

版本号只在 [`rbackup/__init__.py`](../rbackup/__init__.py) 的 `__version__` 里改，`pyproject.toml` 用 `dynamic = ["version"]` 读取它，别在两处各写一遍。

```bash
python -m pip install -U build twine   # 一次性
python -m build                        # 生成 dist/rbackup-X.Y.Z.tar.gz 与 .whl
python -m twine check dist/*           # 校验元数据、README 在 PyPI 上的渲染
```

wheel 只含 `rbackup` 包；sdist 额外带 `docs/`、`tests/` 和 `rbackup.example.toml`（见 [`MANIFEST.in`](../MANIFEST.in)），方便离线阅读文档和跑测试。

先发 TestPyPI 试水：

```bash
python -m twine upload --repository testpypi dist/*
python -m pip install --index-url https://test.pypi.org/simple/ rbackup
```

正式发布：

```bash
python -m twine upload dist/*
```

token 在 <https://pypi.org/manage/account/token/> 创建。项目还没上线时只能选“Entire account”，首次发布成功后再换成只授权 `rbackup` 的项目级 token。

`twine` 的用户名固定填 `__token__`，密码填该 token（以 `pypi-` 开头，约 150 字符）。建议用环境变量或 `~/.pypirc`，别写进命令历史：

```bash
export TWINE_USERNAME=__token__            # Windows: $env:TWINE_USERNAME="__token__"
export TWINE_PASSWORD=pypi-AgEIcHlwaS5vcmc...
```

```ini
# ~/.pypirc
[pypi]
  username = __token__
  password = pypi-AgEIcHlwaS5vcmc...
```

Windows 控制台常见的两个坑：

- `UnicodeEncodeError: 'gbk' codec can't encode character`（进度条的圆点画不出来）：加 `--disable-progress-bar`，或先 `set PYTHONUTF8=1`；
- 403 `Forbidden`：token 不对（长度不足、复制时截断、用了 TestPyPI 的 token 发正式站），或项目级 token 指向了还不存在的项目。

发布前检查：

- 测试全绿（见上一节），`git status` 干净；
- 版本号已递增，且没有发布过的版本号残留；
- `dist/` 里只有本次构建的产物——`twine upload dist/*` 会把目录里所有包一起传，旧产物会报“文件已存在”；
- 上传失败重试时先加 `--verbose` 看服务端原因；PyPI 不支持覆盖同名文件，传错了只能换版本号或 yank。

发布后验证：

```bash
python -m pip install --upgrade rbackup
rbackup --version
```
